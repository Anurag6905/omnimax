# Reference files

Source material the build must match. Read-only: do not edit these.

- `2025-10-01_Client Data Gathering Sheet.xlsx`: the blank client input template. Its five tabs define the input screens and the database tables.
- `Input_Allocations.py`: the goal-allocation script (8 levels). **Add it here** from the project files. Phase 1B ports it to `packages/engine` and tests against it.

Never put a filled-in client sheet in this folder. Real client data stays out of git.
